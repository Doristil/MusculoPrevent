# Photos des exercices

Le code de chaque fiche est la référence unique à utiliser pour ses images.

- Première image : `CODE-1.png` (ex. `EP001-1.png`)
- Deuxième image : `CODE-2.png`
- Troisième image : `CODE-3.png`

Utilisez les mêmes codes que le catalogue : `MP001` à `MP006`, `BR001` à
`BR005`, `EP001` à `EP007`, `TR001` à `TR003`, `DO001` à `DO008`, `LO001`
à `LO006`, `AB001` à `AB003` puis `AB005` à `AB006`, `FE001` à `FE007`,
`CU001` à `CU007` et `MO001` à `MO004`.

`AB004` n'est pas à utiliser : cette fiche ne figure pas dans le référentiel
validé. Les codes ne sont pas renumérotés afin qu'aucune photo déjà renommée
ne soit décalée. Le code `AB007` n'est pas utilisé dans le catalogue actif.
